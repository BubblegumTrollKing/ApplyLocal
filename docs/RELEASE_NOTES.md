Windows x64 build of ApplyLocal, a free local questionnaire assistant.

Download **ApplyLocal-Windows-x64.zip**, extract it, and open **ApplyLocal.exe**. The portable ZIP includes instructions and third-party license notices. The executable is also available separately; accompanying notices are in ApplyLocal-licenses.zip. Python is bundled. Install Ollama and download the free local models through the application before running an assessment.

This release is published only after the Windows automated suite, source GUI test, and frozen executable GUI/browser connection checks pass. **ApplyLocal-test-evidence.zip** contains the actual results and binary checksum. The application is unsigned.

Real Ollama answer accuracy and compatibility with live employer websites have not been validated by these checks. Start with the built-in practice questionnaire and supervise initial use. Personal facts, identity checks, consents and human-only work require your input. The browser stays open when you stop the agent.
